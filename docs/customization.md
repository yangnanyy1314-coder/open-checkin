# 定制说明

## 零代码定制

页面右上角“学员设置”可以修改：

- 训练营名称
- 讲师 / 教练名称
- 学员称呼
- 开营日期
- 14 天目标

## 修改 14 天任务

打开 `index.html`，搜索：

```js
const tasks=[
```

每一天包含：任务名、类型、说明、检查项、交付物。


即可替换成你的课程能力模型。

## 多人在线版

当前数据存储在浏览器 IndexedDB。如果需要学员在手机提交、教练后台实时查看，请增加：

- 用户登录 / 身份鉴权
- 云数据库
- 图片对象存储
- 学员 / 教练数据权限
- 隐私政策与数据删除机制
